## `clasp` 전환 구현 요청과 진행 상태

사용자가 아래 방향의 구현을 요청했다.

| 항목 | 요청된 설계 |
| --- | --- |
| 디렉터리 | `apps-script/career-hub-core/`, `apps-script/career-hub-webapp/`, `scripts/apps-script-release.mjs` |
| 코어 인터페이스 | `healthCheck`, `handlePost`, `setupWorkbook`, `importLinkedGameReferences`, `validateConnection` |
| 설정 | 웹앱 `Script Properties`의 `TARGET_SPREADSHEET_ID`, `WEBHOOK_SECRET`, `REFERENCE_SOURCE_IDS_JSON` |
| 릴리스 흐름 | `push`는 업로드만, `release` 실행 시 기존 deployment에 재배포하여 URL 유지 |
| 제공 명령 | `gas:login`, `gas:push:core`, `gas:push:hub`, `gas:release:hub`, `gas:release:all`, `gas:verify:hub` |
| 검증 API | 인증된 `action: "validate"` 요청은 읽기만 수행하고 행을 추가하지 않음 |

이번 대화에서 구현 요청 이후 실제로 수행한 작업은 기존 `scripts/gamejob_sheet_webhook.gs`, `package.json`, Git 상태를 확인한 것뿐이다. 아직 `apps-script/` 디렉터리 생성, 코드 분리, `@google/clasp` 설치, manifest 작성, 배포 또는 자동화 비밀키 갱신은 수행하지 않았다.

## 보안 및 변경 기준

- 기존 단일 Apps Script 파일에는 고정 비밀키가 들어 있으므로, 해당 값을 요약 파일에 옮기지 않았다.
- `clasp` 전환 시 코드에서 비밀키를 제거하고 Script Properties에 새 값으로 설정한 뒤, 자동화 발신 설정도 같은 새 값으로 갱신해야 한다.
- `.clasp.json`, `.clasprc.json`, `.env*`는 Git 추적에서 제외해야 한다.
- 기존 운영 `/exec` URL은 자동화 연동을 깨지 않도록 유지한다.
- 작업공간에 이미 존재하는 `index.html`, `portfolio.html`, `scripts/verify-ui-flow.mjs` 변경은 이번 Apps Script 업무와 무관하므로 건드리지 않는다.
