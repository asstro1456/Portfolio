# GPT 전달 채팅

아래 문서를 기준으로 Figma 후속 탭 Revision을 정리해줘.

기준 문서:
`figma/2026-06-11_portfolio-coach_followup_tabs_codex_answers.md`

중요한 전제:

1. 이번 작업은 사이트 코드나 실제 로직 수정이 아니다.
2. 코드 구조는 Figma 화면 정보 설계를 맞추기 위한 참고 기준으로만 사용한다.
3. Figma 안에서 인터랙션 표현, 탭 상태, 버튼/카드 배치, UI 레이아웃, 텍스트 가독성만 정리한다.
4. 실제 서비스 로직 변경, 새 기능 추가, 데이터 구조 변경처럼 보이는 화면은 만들지 않는다.
5. 새 컴포넌트가 필요하면 만들기 전에 먼저 질문한다.
6. Mobile / Tablet 프레임은 새로 만들지 않는다.

우선순위:

P0:
- 서류 피드백
- 포트폴리오
- 추천 공고

P1:
- 공고 분석
- 면접 대비
- PDF 출력

P2:
- 면접 기본 준비
- 인성검사

작업 기준:

- `Desktop / 정보 입력 - Revision`의 Navigator, 본문 폭, 카드 밀도, 섹션 구조를 후속 탭에도 맞춘다.
- 기본 화면에는 실제 사용자가 보게 될 UI만 남긴다.
- 상태 예시, 조건부 UI, 점선 가이드는 기본 화면이 아니라 component/State Examples 쪽에 분리한다.
- 깨진 문자처럼 보이는 placeholder나 임시 텍스트를 남기지 않는다.
- 텍스트와 버튼이 겹치거나 너무 붙어 보이는 부분을 정리한다.
- 기존 코드에 없는 기능을 화면 중심 요소로 만들지 않는다.
