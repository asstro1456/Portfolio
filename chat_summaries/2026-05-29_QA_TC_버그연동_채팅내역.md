## 최종 반영 구조

### Bug_Report

| 행/컬럼 | 역할 |
| --- | --- |
| 1행 | 컬럼별 `작성` / `자동` 표시 |
| 2행 | 컬럼별 짧은 작성 가이드 |
| 3행 | 헤더 |
| 4행 | 실제 예시 행, 자동화 대상 제외 |
| 5행 이후 | 사람이 작성하는 실제 버그 데이터 |
| K열 | `최초 발견 시트명` |
| L열 | `최초 발견 TC ID` |

### Bug_TC_Link

| 항목 | 내용 |
| --- | --- |
| 신규 컬럼 | `시트명` 추가 |
| 링크 기준 | `시트명 + TC ID + Bug ID` |
| 중복 처리 | 같은 링크가 있으면 새 행을 만들지 않고 기존 행을 보정 |
| 요약 반영 | 활성 링크 기준으로 대상 TC 시트 I열에 Bug ID 요약 반영 |

### Bug_Linked_Sheets

| 컬럼 | 내용 |
| --- | --- |
| 시트명 | 연동 대상 TC 탭 이름 |
| 활성 여부 | `Y` 또는 `N` |
| 등록일 | 등록 날짜 |
| 비고 | 관리 메모 |

기본 등록 시트는 `TC_List_Auto_Test`이고, 검증 중 `TC_List_Sever`도 활성 등록했다.

검증 중 발견해 수정한 문제:

- 숫자형 TC ID가 Google Sheets 날짜 표시처럼 읽히는 문제를 `normalizeTcIdValueLocal_`로 보정.
- 기존 `Bug_TC_Link` F열 드롭다운이 새 구조에서 링크 작성 오류를 만드는 문제를 제거.
- 실패한 이전 실행으로 생긴 중복 링크의 빈 상태/날짜를 보정하도록 수정.

## 남은 리스크

- 스프레드시트에서 새 메뉴가 바로 안 보이면 시트 새로고침이 필요하다.
- Apps Script 커스텀 메뉴는 항목별 툴팁을 직접 지원하지 않아 `버튼 설명 보기` 팝업 방식으로 안내한다.
- 현재 활성 등록된 실제 탭 이름은 `TC_List_Sever`다. 사용자가 말한 `TC_SNS_Server`가 필요하면 실제 탭을 만들거나 정확한 기존 탭명으로 등록해야 한다.
- 더미 데이터 `BUG-001`, `BUG-002`는 검증용으로 남아 있다. 필요 없으면 사용자가 확인 후 삭제하거나 별도 정리 요청 필요.

## 다음 작업

1. 시트 새로고침 후 `TC Auto Test > 버튼 설명 보기` 확인.

3. `Bug_Report` 5행 이후에 수동 버그를 작성한 뒤 `수동 버그 리포트 링크 반영` 또는 `TC-버그 전체 연동` 실행.
4. GPT Actions에는 `openapi.json`을 넣고, API key 값은 `apps-script/.gas-release.local.json`의 `qaWebhookSecret`을 사용.
