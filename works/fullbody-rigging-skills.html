파츠 준비

fullbody-idle-parts는 전신 표시 크기, 허용된 움직임, 가려진 영역의 복원과 픽셀 소유권을 정합니다. 공통 캔버스와 좌표를 유지하고 얼굴·옷·실루엣의 승인 범위를 보존합니다.

Unity 연결

ut-fullbody-rigging-harness는 프로젝트의 기존 importer·prefab·clip을 사용해 본 배열, SpriteSkin 참조, 메시·웨이트, 레이어 순서와 clip binding을 점검합니다. unity-animation-clips는 시각 연출을 편집 가능한 AnimationClip으로 남기고 기존 이벤트·연결 범위와 맞추는 절차입니다.

검증 흐름

원화·파츠 선행 검수 → 본·메시 연결 → 실제 전신 크기에서 루프 확인 → 실패 자세와 경계 재검수. 아트 준비, 연결 상태, 동작 품질, 영상 파일 검사를 따로 기록합니다.

적용 범위

Project UT 전용 하네스와 범용 파츠 준비 스킬을 구분합니다. 프리뷰나 정지 화면만으로 Play Mode, 실제 기기 성능, 자연스러운 연속 동작을 확인했다고 하지 않습니다.
