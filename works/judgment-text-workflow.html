판단 자료 → 문서 초안 워크플로

선별한 텍스트 자료에서 근거를 찾고 검토 계획을 연결해, 문서 초안과 점검 결과를 만드는 오프라인 실행기입니다.

2026.11.04 로컬 구현·스킬 지침을 확인해 정리한 소개입니다. 기능 설명과 실제 실행 검증의 범위를 구분합니다.

입력과 출력

입력은 요청 JSON, 검토 계획 JSON, 고정된 텍스트 스냅샷입니다. 자료 탐색 뒤 사람이거나 AI인 검토자가 관련성·조건·문장별 근거를 작성합니다. 실행기는 그 연결을 검사해 Markdown 초안과 audit.json을 만듭니다.

두 단계 실행

discover: 고정 자료 안에서 키워드로 후보를 찾고 원문·화자·판단 상태를 전달합니다. run: 선택 근거와 요구사항 연결, 스냅샷 해시·기간·차단 상태를 검사합니다. 검토가 빠졌거나 자료가 차단되면 점검 결과만 남기고 초안을 만들지 않습니다.

구성 파일

workflow.py — 탐색·입력 검증·초안 출력 test_workflow.py — 실행기 테스트 snapshot-ref.json — 자료 버전 참조 examples/request.json, examples/plan.json — 입력 예제 package_verify.py — 스냅샷 파일 검사

사용 범위

Python 3.10 이상 표준 라이브러리로 실행합니다. 웹 조사나 모델 API 호출, 원격 동기화를 수행하지 않습니다. 키워드 일치는 관련성의 증명이 아니며 정상 종료도 사람의 검토를 기다리는 상태입니다. 개인 판단 발췌가 들어 있는 원본 패키지는 비공개 자료로 유지하고, 여기에는 실행 구조만 소개합니다.
