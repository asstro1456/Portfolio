작업 연결

crack-idea-harness가 새 제작·수정·검수·이미지 작업을 구분하고 필요한 단계로 연결합니다. 캐릭터 빌더와 스토리 빌더는 서로 다른 입력 필드·제약·게시 단계를 다룹니다. validate_run.py는 작업 기록의 구조를 점검합니다. 구조 검사만으로 원고의 재미나 독자 반응이 입증되는 것은 아닙니다.

원고 검토

fiction-workbench는 세계관, 인물, 대사, 선택권, 분기와 엔딩처럼 질문의 성격에 맞는 창작 스킬을 고릅니다. 확정 설정·의도적 미정·독자에게 숨긴 비밀을 구분하고 플레이어의 선택권을 확인합니다.

직접 구성한 부분과 외부 출처

개인 작업에 맞춘 진입·분기·서비스 입력·검증 절차를 소개합니다. 연결된 모든 창작 스킬을 직접 만든 것으로 세지 않습니다. 예를 들어 dialogue, character-arc, systemic-worldbuilding 등은 jwynia/agent-skills에서 가져와 로컬 환경에 맞춘 항목이며 설치 출처와 변경점을 별도로 기록합니다.
