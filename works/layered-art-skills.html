PSD 제작·이미지 검수 스킬

편집 가능한 레이어 구조를 만들고, 원화 보존과 이미지의 실제 사용 맥락을 함께 점검하는 스킬 묶음입니다.

2026.11.04 로컬 구현·스킬 지침을 확인해 정리한 소개입니다. 기능 설명과 실제 실행 검증의 범위를 구분합니다.

각 스킬의 역할

layered-psd: 이미 나뉜 PNG를 PSD로 저장하고 레이어 순서·좌표·알파·합성을 확인합니다. 평면 이미지의 레이어 추정 재구성과 단순 파일 포장을 구분합니다. review-ai-generated-art: 형태·경계·의미 전달·수정 전후 차이를 검토합니다. review-ui-art: 개별 이미지의 차이보다 화면 내 역할, 시각적 위계와 사용 중인 자산 그룹을 확인합니다. anime-image-direction: 캐릭터·소품·구도·투명도를 보존하며 2D 애니메이션풍 표현을 유지하는 지침입니다.

실제 구성

PSD 저장용 pack_psd.py와 검사 스크립트, UI 자산의 이미지 모아보기·Unity 참조 검색 스크립트, 역할별 검수 기준 문서가 있습니다. 도구의 기술 검증과 사람·AI의 시각 판단을 분리합니다.

저장 도구의 한계

PSD 저장기는 RGB 8비트·Normal 혼합·평면 레이어 목록을 지원합니다. 그룹, 조정층, 실제 편집 마스크, 다양한 혼합 모드를 모두 보존하는 편집 앱은 아닙니다. 평면 이미지에서 원래의 제작 이력을 복구하지 않습니다. 복잡한 이미지의 자동 선·색·음영 분리는 외형 보존 검수를 통과한 범용 기능으로 소개하지 않습니다.
