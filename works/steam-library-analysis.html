장르 집계와 해석 기준

복수 장르 게임은 해당하는 각 장르에 포함됩니다. 따라서 장르별 게임 수와 플레이시간을 더하면 실제 전체 합계보다 커집니다. 시트의 장르 비중은 이 중복 포함 합계를 분모로 사용합니다. Indie가 Steam 장르에 포함된 게임을 인디로 분류합니다. 기능 태그는 Steam Categories를 사용한 값이며, 사용자 태그와는 구분합니다. 플레이 성향은 관측값을 바탕으로 한 해석입니다.

자료와 확인 범위

다운로드 파일은 로컬에 보관된 장르 집계 수정본입니다. 원본을 재계산·수정하지 않고 그대로 제공합니다. 게임 데이터의 143개 항목과 플레이시간 합계, 12개 장르의 게임 수·플레이시간을 독립 집계해 저장값과 대조했습니다. 원천은 Steam 커뮤니티 저장 HTML이며, 장르·개발사·배급사·기능 분류는 파일에 기록된 Steam App Details API 자료를 사용했습니다. 이번 게시에서 최신 Steam 데이터를 다시 수집하지 않았습니다. 날짜 기반 수식은 엑셀에서 열 때 기준일에 따라 달라질 수 있습니다.
