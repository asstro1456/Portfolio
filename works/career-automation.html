채용 자료 수집·Career Hub

채용 공고와 지원 준비 자료를 수집하고, 중복과 경력 조건을 정리해 Google Sheets로 전달하는 자동화 코드입니다.

2026.11.04 로컬 구현·스킬 지침을 확인해 정리한 소개입니다. 기능 설명과 실제 실행 검증의 범위를 구분합니다.

코어 코드 보기 ↗수집 코드 보기 ↗

처리 흐름

공고 수집 → 상세 요구사항 분류 → 중복 제거 → 주간 자료 준비 → 인증된 웹앱으로 시트 적재. 목록의 경력 표기와 본문 요구 경력을 나누고, 판정이 어려운 경우 수동 확인 상태를 남깁니다.

구성 파일

scripts/gamejob-collect.mjs, gamejob_full_collect.mjs — 공고 수집 scripts/gamejob-weekly-collect.mjs — 주간 처리 scripts/gamejob-backup-report.mjs — 수동입력경력 이월 점검 apps-script/career-hub-core/Core.gs — 시트 적재·중복 제거·집계 apps-script/career-hub-webapp/Main.gs — 인증·요청 처리

운영을 고려한 부분

코어와 웹앱을 분리하고 운영 설정은 코드 밖에서 읽습니다. 자료를 전송하지 않는 점검 모드와 실제 시트 반영을 구분합니다. 목록 정보만으로 지원 가능성을 확정하지 않도록 상세 경력과 수동 확인 결과를 함께 다룹니다.

공개 범위

기존 공개 저장소의 코드로 연결합니다. 개인 시트나 운영 웹앱을 체험용으로 실행하지 않습니다. 이번 수록 작업은 페이지·링크 확인이며 실제 공고 수집이나 시트 갱신을 재실행한 것은 아닙니다.
