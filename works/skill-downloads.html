파일 구성과 확인 범위

각 ZIP에는 실제 SKILL.md, 해당 폴더의 참고 문서·스크립트·정적 자산과 사용 안내가 들어 있습니다. 개인 DB·대화 원문·인증 설정·캐시는 포함하지 않습니다. 개별 ZIP은 연결된 다른 스킬이나 외부 서비스를 자동 설치하지 않습니다. 압축 해제 검사, 포함 파일과 원본의 해시 비교, Python 구문 검사를 수행했습니다. review-ui-art의 UI 메타데이터 파일 1개만 배포 사본에서 UTF-8로 변환했습니다. 설치된 원본은 바꾸지 않았습니다. 모든 스킬의 실행·새 PC 설치·서비스 연결을 검증한 것은 아닙니다. 사용 전 필요한 도구와 프로젝트 범위를 확인하세요. 이번 공유본의 별도 검토 채팅은 사용자 요청으로 생략했습니다.
