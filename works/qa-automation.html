QA 테스트 케이스·버그 연동

테스트 케이스와 버그 자료의 연결을 검사하고, 상태와 집계를 Google Sheets에서 관리하는 Apps Script 도구입니다.

2026.11.04 로컬 구현·스킬 지침을 확인해 정리한 소개입니다. 기능 설명과 실제 실행 검증의 범위를 구분합니다.

핵심 기능

테스트 케이스 시트의 헤더·상태 선택·서식을 준비하고 버그 시트와의 연결을 검증합니다. 수동으로 작성한 버그 보고와 테스트 케이스 요약을 연결하며 Hub 집계를 미리 확인할 수 있습니다.

구성 파일과 동작

apps-script/qa-tc-webapp/Main.gs setupTcSheet — 테스트 케이스 시트 구성 validateBugLinks — 버그·테스트 케이스 연결 검사 syncBugSummaryToTc — 버그 요약 동기화 syncManualBugReports — 수동 보고 반영 previewHubCounts — 집계 미리보기

확인과 반영 분리

시트 연결·입력·인증을 먼저 확인하고 읽기 전용 검증과 실제 변경을 구분합니다. 배포 스크립트는 소스 업로드와 운영 버전 배포를 나누며, 운영 확인 실패에 대비한 이전 버전 복구 흐름을 갖추고 있습니다.

공개 범위

기존 공개 코드와 QA 작업 사례를 연결합니다. 실제 운영 시트 데이터는 이 소개에 복사하지 않았으며, 버튼을 눌러 개인 시트를 변경하는 체험판도 아닙니다. 코드의 현재 존재와 실제 운영 테스트 결과를 구분합니다.
