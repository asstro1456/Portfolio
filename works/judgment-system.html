SKILL.md와 참고 문서·스크립트가 포함된 개인 환경 원본입니다. 원본의 경로·외부 도구 의존성을 확인한 뒤 사용하세요. 개인 DB와 계정 설정은 포함하지 않습니다.

작업에서 필요한 이유

같은 수정이 반복되거나 예전 판단이 다른 장면에 잘못 적용되는 문제를 줄이기 위한 체계입니다. 사용자 발언, AI 제안, 검토 중인 후보와 확정 기준을 분리합니다.

처리 흐름

출처 등록 → 후보 분류 → 범위·조건 검토 → 기록 → ID로 다시 읽어 확인. 검색할 때는 프로젝트·분야·대상·원문·후속 정정을 확인합니다. 대체된 판단과 충돌은 이력으로 남기고, 미검증 개선 제안은 별도 큐에서 관리합니다.

실제 구현

SQLite와 Python CLI를 사용합니다. judgments.py가 기록·조회 진입점이며, retrieval.py는 검색, conflicts.py는 충돌, learning.py와 evaluation.py는 피드백·평가 기록, skill_queue.py는 개선 제안 큐를 담당합니다. 단위 테스트 파일과 조회 사례 검증기가 포함되어 있습니다. 이 페이지는 구조를 소개하며 테스트 전체를 새로 실행한 결과는 아닙니다.

판정의 범위

검색 가능한 기록 시스템이며 모델을 재학습하는 기능은 아닙니다. 검색 성공과 현재 작업에 대한 적합성, 사용자 승인과 결과물 품질을 각각 확인합니다. 개인 DB와 대화 원문은 이 페이지에 포함하지 않습니다.
