이미지 경계 전달 도구

말로 설명하기 어려운 수정 위치를 이미지 위에 표시하고, 원본 좌표와 함께 전달하는 브라우저 도구입니다.

2026.11.04 로컬 구현·스킬 지침을 확인해 정리한 소개입니다. 기능 설명과 실제 실행 검증의 범위를 구분합니다.

도구 열기 ↗공유본 ZIP 다운로드 ↓

어떤 문제를 다루나

“이 부분을 고쳐 주세요”라는 말만으로는 머리카락과 옷, 선과 그림자의 경계를 정확히 전달하기 어렵습니다. 이미지 위에 색별 선과 설명을 남겨 수정 대상과 보존 영역을 함께 전달합니다.

사용 흐름

이미지 열기 → 펜으로 경계 표시 → 색의 의미와 설명 작성 → PNG·JSON 내보내기. 펜·표시 지우기·실행 취소, 확대·이동을 지원합니다. Shift+클릭은 남아 있는 이전 선의 끝에서 직선으로 연결하고, Shift+휠은 펜 굵기를 조절합니다. 작업 폴더를 선택하면 요청·원본·응답을 로컬 파일로 연결합니다. 제출 뒤 파일 위치를 Codex에 전달해 같은 이미지 버전을 검토하도록 구성했습니다.

구성 파일

ai-boundary-tool.html — 화면·펜 입력·로컬 저장 codex-local.cjs — 요청 파일 작성과 응답 무결성 검사 AI-사용법.md / 사용법.pdf — 사용자 및 AI용 안내 examples/ — 경계 표시 예시

사용 범위

2.0.1 공유본입니다. 이미지 표시·선 그리기와 파일 내보내기는 브라우저에서 동작합니다. Codex를 자동 호출하거나 원화를 자동 수정하는 도구는 아닙니다. 폴더 저장은 데스크톱 Edge·Chrome을 기준으로 만들었습니다. 파일 핸들 시험과 실제 폴더 선택·권한 허용을 구분하며, 실사용 폴더 저장과 모바일 저장 지원은 별도 확인이 필요합니다.
