핵심 기능

제안서, 시스템, 전투, 콘텐츠, 밸런스, 경제, UI/UX, 스토리, 운영 등 요청한 종류만 작성합니다. 전체 기획서를 요청한 경우에만 통합 범위로 확장합니다.

작성 흐름

요청 해석 → 문서 종류·범위 선택 → 필요한 작성 계약과 JSON 골격 생성 → 내용 작성 → HTML 렌더 → 자동 검증. compile_context.py가 작성 계약을 추출하고, render_gdd.py와 validate_gdd.py가 HTML 출력과 검증을 맡습니다. 빠른 초안 모드에서도 미정 수치는 가정으로 표시하고 검증을 유지합니다.

검수 흐름

원문에서 입력 조건, 판정, 성공·실패, 관찰 가능한 피드백과 수용조건을 확인합니다. 구현·판정 검수에서는 질문으로 규칙의 공백을 드러내고, 수정 요청이 있을 때만 원문을 바꿉니다. 게임 규칙과 개발 구현 선택을 구분해 클래스·서버 구조 같은 기술 해법을 기획서에서 임의 확정하지 않도록 구성했습니다.
