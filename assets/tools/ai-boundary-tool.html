열린 이미지 없음

원본 이미지 + 표시 PNG + 전달 문구를 채팅에 첨부하세요. 좌표를 다룰 수 있는 AI에는 JSON도 함께 전달하세요.

처음 사용한다면
  1. 이미지를 열고 색상별 뜻을 확인합니다.
  2. 펜으로 경계를 그리거나 수정할 곳을 둘러 표시합니다. 이동 모드에서는 그림을 옮겨 볼 수 있습니다.
  3. 수정 설명을 적고 PNG, JSON, TXT를 저장합니다.
  4. 원본과 저장한 자료를 AI 채팅에 직접 첨부합니다.
이 도구는 표시와 설명을 만드는 도구입니다. 이미지 편집이나 AI 전송은 수행하지 않습니다. JSON을 다시 열려면 사용했던 동일한 원본 파일을 먼저 열어 주세요.
