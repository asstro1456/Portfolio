# 기획서 허브

`index.html`을 열면 최신 기획서와 작성 정보를 볼 수 있습니다. 제출할 때는 `이동현_기획서허브.pdf`를 사용하세요.

## 구성

- 1쪽: 최신 기획서 27개 바로가기. 문서 제목은 공개 원문, ‘상세’는 PDF 안의 작성 정보로 연결됩니다.
- 2-7쪽: 최신본별 날짜·날짜 기준·분류·작성 시기·작성 기간.
- 8-12쪽: 확인된 구버전 38개. HTML에서 ‘구버전 부록 포함’을 해제하면 PDF에서 빠집니다.

## 업데이트

1. HTML 상단의 **문서 목록 수정**을 누르고 문서를 고릅니다.
2. 내용을 고치거나 **새 버전 추가**를 누릅니다. 같은 ‘버전 묶음’의 새 최신본을 반영하면 이전 최신본은 구버전으로 이동합니다.
3. **목록에 반영 → 닫기 → 수정본 HTML 저장**을 누릅니다. 내려받은 HTML이 변경 내용이 담긴 새 원본입니다. 기존 파일을 자동 덮어쓰지는 않습니다.
4. 저장한 HTML을 다시 열고 **인쇄 / PDF 저장**을 누릅니다. Chrome 또는 Edge에서 ‘PDF로 저장’, A4, 배율 100%, 머리글·바닥글 끄기를 사용하세요. 글이 추가됐으면 미리보기에서 잘림을 확인합니다.

HTML 안에 목록 데이터가 포함되어 있어 다른 파일 없이 열고 수정할 수 있습니다. `data.json`은 최초 수집 당시의 참고 자료이며, HTML에서 고친 내용이 자동으로 동기화되지는 않습니다. 새 기획서가 30개를 넘으면 최신본 목차가 다음 페이지로 이어집니다.

## 날짜와 범위

- 문서에 적힌 날짜와 변경 이력을 우선했습니다. 날짜가 없으면 Drive 수정일임을 밝혔으며, 사본 생성일을 작성일로 취급하지 않았습니다.
- ‘기록상 N일’은 변경 이력의 첫 날짜부터 마지막 날짜까지의 경과 일수입니다. 실제 작업에 투입한 일수는 아닙니다. 실제 기간이 확인되지 않은 항목은 ‘미확인’으로 남겼습니다.
- 최신본은 확인한 파일의 버전과 현재 공개본을 기준으로 선정했습니다. 구버전 부록은 확인한 파일 38개로, Drive의 모든 과거 수정 이력을 포함하지는 않습니다.
- 림버스 컴퍼니 업데이트 제안서는 공개 권한이 없어 링크 목록에서 제외했습니다. 공개 접근이 가능해진 후 목록에 추가하면 됩니다.

## 확인 결과 · 2026-09-06

A4 12쪽 전체 렌더링에서 글·페이지 번호 겹침을 확인했습니다. PDF 외부 링크 92개(문서 65개), 내부 이동 링크 41개의 연결 대상이 유지됩니다. 65개 원문은 로그인 정보 없이 웹 요청으로 열렸으며, Drive의 공개 권한도 확인했습니다. 권한이나 원문 주소가 나중에 바뀌면 다시 확인해야 합니다.

목록 변경, 새 버전 추가에 따른 이전 버전 이동, 수정 HTML 저장·재열기, 구버전 제외, 모바일 너비를 검증했습니다. 기존 제출 문서나 웹 배포는 변경하지 않았습니다.

`verification/`에는 검증 기록이 있습니다. `verify-export.cjs`는 현재 PC에 설치된 Portfolio의 Playwright를 사용해 HTML 기능을 확인하고 PDF를 다시 만드는 관리용 파일입니다.
