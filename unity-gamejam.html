게임 기획 포트폴리오
프로젝트제작 방식
Unity AI Game Jam · 공개용 포트폴리오

플레이 규칙을 설계하고
구현 결과로 검증합니다.

플레이어가 무엇을 보고 어떤 선택을 하게 할지 생각하며 규칙과 화면의 동작 조건을 정리합니다. 프로토타입을 제작하고 실제 결과를 확인하며 기획을 수정합니다.

대표 프로젝트

기획 의도, 구현 범위, 피드백에 따른 변경 경험을 중심으로 정리했습니다.

개인 프로젝트 · 2026.07

Rune Trace

경로를 고민할 시간을 주기 위해 실시간 디펜스를 턴제 퍼즐로 변경했습니다. 웹 프로토타입의 플레이 로그를 살피며 입력에 어려움을 겪는 구간을 확인하고 다음 테스트 기준을 정리했습니다.

기업 협업 · 2026.05–07

냥냥스타

이미지 공유 기능을 제안하고 제작 여건에 맞춰 범위를 조정했습니다. 글로 전달하기 어려운 조작을 프로토타입으로 보여주고 구현 결과의 차이를 QA로 추적했습니다.

팀 프로젝트 · 2026.04~

Project UT

UI/UX 및 내러티브 연출을 기획하고 Unity에서 UI, 애니메이션, VFX 제작에 참여했습니다. 기능 조건과 입력 우선순위를 정리하고 개발팀과 구현·수정 사항을 조율했습니다.

팀 프로젝트 · 2026.03–04

Project BB

무작위 맵 생성, 공간 배치, 방 진행 규칙을 나눠 설계했습니다. Unity에서 실제 플레이 공간을 확인하며 입구 세이프 존을 적용했습니다.

팀 프로젝트 · 2026.02–03

나린가락

힐링 감성과 제작 일정을 함께 고려해 시나리오 분량을 조정하고 팀 역할 및 진행 상황을 공유해 5개 스테이지의 게임으로 완성했습니다.

팀 프로젝트 · 2026.01

Exit Value

시나리오를 데이터 테이블과 관계도로 정리해 기능과 연결했습니다. 엔진 적용 중 발생한 문제를 구조 개선 방향에 반영했습니다.

제작 방식

아이디어를 전달할 때 기대하는 플레이 경험과 구현 규칙을 함께 정리합니다. 애매한 입력과 예외 상황은 명세로 구분하고, 설명만으로 부족한 조작은 프로토타입으로 보여줍니다. Unity 및 AI 개발 도구를 활용할 때에도 결과를 직접 확인하고 수정합니다.
