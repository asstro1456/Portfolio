# 원문 복원: The First Descendant Unreal Engine 5 시네마틱 Houdini 활용기

## 문서 정보

- 형식: NDC 2026 기술 발표 및 질의응답
- 발표: 김준영, 넥슨게임즈 매그넘 스튜디오 VFX 아티스트
- 대상: The First Descendant 트레일러·인게임 컷신 VFX 제작
- 핵심 도구: Houdini, Unreal Engine 5, Niagara, Vertex Animation Texture(VAT), AnimToTexture
- 복원 기준: PDF의 줄바꿈·시간 구분자·기술 용어·명백한 음성 인식 오류를 교정하고, 슬라이드가 있어야 특정 가능한 노드 값은 기능 중심으로 복원함

## 남은 확인 필요 항목

- 발표자 소속 세부 표기는 음성에서 `매그넘 스튜디오`로 복원했으나 원문 PDF만으로 영문 조직명을 확정하지 못했다.
- 09:24의 표정 개수는 앞 문장에서는 117개로 들리지만 뒤 문장에서 다른 수치로 오인식되어 `[불확실: 약 117개]`로 유지한다.
- 29분대 참고 자료의 정확한 SIGGRAPH 발표명은 확인하지 못해 연도와 용도만 남겼다.

### 2. 페이셜 애니메이션에 이펙트 메시 붙이기

**김준영 - 06:31**  
첫 번째는 Houdini를 이용한 캐릭터 페이셜 데이터 활용법입니다. 페이셜 애니메이션으로 감정과 분위기를 세밀하게 표현하는 게임이 늘면서 얼굴에 직접 임팩트를 넣어야 하는 상황도 많아졌습니다.

**김준영 - 06:52**  
UV와 텍스처만으로 해결되지 않는 입체적인 효과는 별도 이펙트 메시가 필요합니다. 메시를 단순히 본이나 버텍스에 붙이면 얼굴 피부의 움직임을 따라가지 못해 밀립니다.

**김준영 - 07:20**  
The First Descendant 스토리 컷신에서 볼의 상처가 회복되는 장면을 예로 들겠습니다.

**김준영 - 07:36**  
목표는 캐릭터 얼굴에 원하는 메시를 붙여 페이셜 애니메이션을 그대로 따라가게 하는 것입니다. 일반적인 캐릭터 변형은 Houdini의 Attribute Transfer 계열 노드로 본 캡처 데이터를 옮기면 해결할 수 있습니다.

**김준영 - 08:16**  
하지만 페이셜은 본 캡처 대신 blend shape 속성으로 작동합니다. 같은 방식으로 blend shape 속성을 옮겨 봤지만 정상 동작하지 않았습니다.

**김준영 - 08:40**  
저장된 표정들을 블렌딩하는 구조에서 메시를 추가하면 토폴로지가 달라지고 버텍스 번호가 바뀝니다.

**김준영 - 08:59**  
버텍스가 원래 저장된 위치를 찾지 못해 메시가 깨집니다. 바뀐 메시가 자신의 기준 형태를 다시 인식하도록 만들어야 합니다.

**김준영 - 09:24**  
예시 캐릭터에는 `[불확실: 약 117개]`의 저장 표정이 있습니다. 각 표정을 분리하고 정확히 같은 위치에 이펙트 메시를 붙이는 처리가 필요합니다.

**김준영 - 09:53**  
모션 캡처 배우의 얼굴에 추적점을 찍는 것처럼 3D 캐릭터 얼굴에 tracking point를 배치합니다.

**김준영 - 10:12**  
Scatter에서 source primitive와 source primitive UV 속성을 만들고, Attribute Interpolate에 연결합니다. 각 포인트가 피부 표면의 고유 좌표에 고정되어 피부가 움직일 때 함께 따라갑니다.

**김준영 - 10:50**  
최종 목적은 포인트가 아니라 메시를 붙이는 것입니다. Point Deform으로 포인트가 이펙트 메시를 잡고 같이 움직이게 합니다. 캐릭터 팀에서 받은 찢어진 볼 메시도 같은 방식으로 매칭합니다.

**김준영 - 11:19**  
상처 덩어리는 얼굴 위에 별도 부피가 있지만, 피부 메시처럼 원래 얼굴과 거의 같은 위치에 겹치는 형상은 Scatter 없이 Ray로 source primitive와 UV를 만들고 바로 Interpolate에 연결할 수 있습니다. 완성된 메시를 합쳐 blend shape 데이터를 다시 구성합니다.

**김준영 - 12:06**  
깨짐 없이 얼굴을 따라가는지 확인한 뒤, 본 데이터도 가져와 FBX로 내보냅니다. Unreal Engine에서도 페이셜 데이터가 정상 인식됩니다.

**김준영 - 12:38**  
볼의 미세한 떨림에도 이펙트 메시가 텍스처처럼 밀착해 움직이는 결과를 얻었습니다.

### 3. Particle VAT로 포말과 물보라 만들기

**김준영 - 12:58**  
두 번째는 물 이펙트입니다. 액체 VFX는 구현이 까다롭고 저도 여러 방식을 시험했습니다. 이번에는 포말 느낌의 물을 다룹니다.

**김준영 - 13:17**  
보통 물을 렌더링해 sprite로 쓰거나 dynamic remesh VAT로 구현합니다. Sprite는 해상도 한계가 있고, dynamic remesh는 형상이 정교할수록 용량이 크게 늘어납니다. 가까이서 깨져 보이거나 프레임과 디테일을 줄여야 하는 문제가 생깁니다.

**김준영 - 13:54**  
입자감이 살아 있는 splash를 위해 Particle VAT를 선택했습니다.

**김준영 - 14:16**  
예시에서 dynamic remesh는 여러 장의 2K·4K 텍스처가 필요했지만 Particle VAT는 1K 텍스처 한 장으로 구성할 수 있었습니다. 원본 형상 품질 차이는 후속 단계에서 보완합니다.

**김준영 - 14:48**  
Houdini 제작은 크게 세 단계입니다. 먼저 Water Tank에서 fluid simulation으로 splash의 기본 형태를 만듭니다.

**김준영 - 15:05**  
Velocity 값을 기준으로 순간적으로 위로 튀는 particle만 그룹화하고, 그 그룹을 emitter로 사용해 whitewater simulation을 한 번 더 수행합니다.

**김준영 - 15:37**  
첫 시뮬레이션을 그대로 사용하면 바닥에 고인 물까지 포함됩니다. 바닥을 잘라 내면 칼로 자른 듯한 경계가 생깁니다.

**김준영 - 16:07**  
Whitewater simulation을 추가해 필요한 splash만 자연스럽게 분리합니다. 설정은 대체로 기본값을 사용하고, 엔진에서 감당할 수 있도록 particle 수를 줄입니다.

**김준영 - 16:46**  
Particle VAT는 기본적으로 motion blur가 나오지 않으므로 Houdini에서 계산된 velocity를 사용해야 합니다. Velocity를 color로 변환해 texture로 저장합니다.

**김준영 - 17:03**  
Material에서 이 값을 연결하면 각 particle의 이동 방향을 계산할 수 있고 multiplier로 motion blur 길이를 조절할 수 있습니다.

**김준영 - 17:35**  
Motion blur는 비어 보이는 부분을 채우고 뭉친 부분의 입체감을 살려 품질을 크게 높입니다. Niagara에서 spawn해 사용할 수 있습니다.

**김준영 - 18:06**  
수면 위 출렁이는 부분만 따로 분리하면 포말이 생기는 decal과 비슷한 방식으로도 활용할 수 있습니다.

### 4. AnimToTexture로 군중 VAT 최적화

**김준영 - 18:28**  
세 번째는 Houdini를 부수적인 전처리 도구로만 사용한 사례입니다. The First Descendant 컷신의 콘서트 장면에는 많은 군중이 필요했습니다.

**김준영 - 18:52**  
모든 군중을 skeletal mesh로 사용할 수 없어 캐릭터 애니메이션을 VAT로 제작했습니다. 처음에는 Houdini로 만들었지만 테스트 결과 Unreal의 AnimToTexture 플러그인이 최적화에 더 유리해 그 방식을 채택했습니다.

**김준영 - 19:20**  
Houdini에서는 간단한 재가공만 했습니다. 군중은 최대한 가볍게 많이 배치하는 것이 핵심입니다.

**김준영 - 19:48**  
VAT를 가볍게 만드는 가장 확실한 방법은 버텍스 수나 애니메이션 길이를 줄이는 것입니다.

**김준영 - 20:05**  
애니메이션이 지나치게 어색해지지 않는 선에서 2~4배 빠르게 만들어 길이를 줄였습니다. 이 메시를 Unreal로 가져와 AnimToTexture로 VAT를 생성했습니다.

**김준영 - 20:32**  
플러그인은 텍스처가 한 장 더 필요했지만 전체 용량이 Houdini 방식보다 작았습니다. Material에서 애니메이션을 원래 속도로 다시 느리게 재생합니다.

**김준영 - 21:11**  
모든 군중이 같은 타이밍과 속도로 움직이면 어색하므로 Niagara dynamic parameter로 time offset을 줍니다.

**김준영 - 21:32**  
속도를 다시 늦추면 프레임이 끊겨 보일 수 있어 material에서 누락된 프레임을 보간합니다.

**김준영 - 21:48**  
보간한 쪽이 훨씬 부드럽습니다. 원본과 약간 오차가 생길 수 있으므로 장면을 보며 2~4배 범위에서 조절합니다.

**김준영 - 22:29**  
Niagara Mesh Renderer가 여러 타이밍에 랜덤 출력하도록 설정하고, 군중 섹션마다 원하는 범위와 위치에 배치했습니다.

**김준영 - 22:54**  
배치 편의를 위해 Niagara를 local space로 설정했습니다. 그러나 actor scale을 조절하면 군중 간격뿐 아니라 메시 크기도 바뀌는 문제가 생겼습니다.

**김준영 - 23:10**  
Scratch Pad에서 메시 크기는 actor scale의 영향을 받지 않고 위치 간격만 늘어나게 만들었습니다. 카메라 거리에 따른 LOD도 적용했습니다.

**김준영 - 23:49**  
LOD 없이도 많은 군중을 배치할 수 있었고, LOD를 적용하자 더 가벼워져 프레임을 약 두 배 확보했습니다.

### 5. Skeletal animation과 VAT를 분리해 제어하기

**김준영 - 24:13**  
네 번째는 VAT를 조금 다르게 활용한 사례입니다.

**김준영 - 24:32**  
컷신에서는 캐릭터 움직임에 정확히 맞춰 이펙트를 통째로 베이크해야 할 때가 있습니다. 애니메이션이 수정되면 Houdini에서 다시 이펙트를 맞추고 VAT를 베이크해 Unreal에 재적용해야 하므로 수정이 누적될수록 비용이 큽니다.

**김준영 - 25:06**  
VAT가 보통 static mesh에서 작동한다는 전제를 바꿔, static mesh를 skeletal mesh로 만들면 본 애니메이션과 이펙트 움직임을 동시에 쓸 수 있지 않을까 시험했습니다.

**김준영 - 25:42**  
첫 사례는 color animation을 mask처럼 사용한 것입니다. 몸에 빗물이 흐르는 animation을 color 값만 VAT texture로 출력했습니다. Attribute Transfer로 본 캡처 데이터를 옮겨 skeletal mesh로 구성했습니다.

**김준영 - 26:22**  
Skeletal mesh에 VAT를 적용하면 몸의 움직임은 animator가 만든 skeletal animation을 따르고, 빗물의 타이밍과 속도는 VAT parameter로 독립 제어할 수 있습니다. 기존처럼 모두 VAT로 베이크했다면 빗물 속도를 바꿀 때 캐릭터 애니메이션도 같이 느려졌을 것입니다.

**김준영 - 27:03**  
얼굴에 흐르는 빗물은 첫 주제의 페이셜 데이터 매칭도 추가합니다. 팔에 붙은 전기 이펙트 메시에는 본 캡처 데이터만 이식해, 전기의 세부 움직임은 VAT로 제어하면서 전체 위치는 팔을 따라가게 만들었습니다.

**김준영 - 27:53**  
다른 컷신에서는 몸속 기생충의 꿈틀거림만 VAT로 재생하고 전체 메시와 캐릭터 움직임을 결합해 각각 제어했습니다.

### 6. Coverage 속성으로 rim light와 환경색 만들기

**김준영 - 28:27**  
마지막은 이펙트 메시의 외곽에 rim light를 넣은 사례입니다. Houdini에서 리소스를 보기 좋게 만들어도 실제 장면에서는 환경과 카메라 각도에 따라 어둡거나 평평하게 보일 수 있습니다.

**김준영 - 28:58**  
외곽 rim light pass를 따로 추가해 환경에 상관없이 입체감을 살렸습니다. 2019년 SIGGRAPH 자료에서 coverage 영역을 color channel로 넘겨 Alembic에 활용한 사례를 참고했습니다.

**김준영 - 29:29**  
Coverage node로 메시 외곽 영역을 구하고 원하는 만큼 날카롭게 범위를 설정합니다.

**김준영 - 29:44**  
Coverage 값을 별도 attribute로 만들고 normal과 조합해 Houdini에서 look을 미리 확인합니다.

**김준영 - 30:13**  
같은 계산을 Unreal material에서 할 수 있으므로 Houdini 단계의 일부 연산은 생략할 수 있습니다.

**김준영 - 30:43**  
VAT position texture의 사용하지 않는 alpha channel에 coverage 값을 저장했습니다. 추가 texture 없이 이 값을 reflection, normal, opacity 계산에 활용합니다.

**김준영 - 31:09**  
외곽 입체감을 만들거나 가운데가 얇은 막처럼 투과하는 느낌을 표현할 수 있습니다.

**김준영 - 31:51**  
반대로 coverage 영역에 환경색을 입혀 주변 색이 자연스럽게 묻어나오게 할 수도 있습니다. VFX뿐 아니라 다른 파트에서도 여러 방식으로 Houdini를 활용하는 데 도움이 되길 바랍니다.

**김준영 - 32:24**  
발표를 들어 주셔서 감사합니다.
