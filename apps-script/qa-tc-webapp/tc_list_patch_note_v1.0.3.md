# tc_list_patch note v 1.0.3

## 수정내용
- 수정 내용 1: `Bug_Report`에 `빌드 버전`, `재확인 빌드 버전`, `버전 확인 결과` 컬럼 추가.
- 수정 내용 2: `빌드 버전`은 필수 입력으로 설정하고 드롭다운 값은 `0.0.1`, `1.0.0`으로 제한.
- 수정 내용 3: `재확인 빌드 버전`은 다음 버전 재검증 시 선택 입력으로 사용.
- 수정 내용 4: `버전 확인 결과` 드롭다운 추가: `미확인`, `재현됨`, `부분 수정`, `수정 확인`, `재발`.
- 수정 내용 5: 다음 버전에도 버그가 남은 경우는 `재현됨`, 일부만 고쳐진 경우는 `부분 수정`으로 기록하도록 구조 반영.
- 수정 내용 6: 기존 Bug_Report 데이터는 삭제하거나 자동 덮어쓰지 않고 새 컬럼만 추가.

## 검증
- `npm run gas:check` 통과.
- `openapi.json` JSON 파싱 검증 통과.
- Apps Script QA 웹앱 버전 20 배포 완료.
- `formatBugSheets` 실행으로 `Bug_Report` 컬럼/드롭다운 적용 완료.
- `Bug_Report` 헤더 확인: `빌드 버전`, `재확인 빌드 버전`, `버전 확인 결과` 추가.
- `validateBugLinks` 확인: 오류 0건, 경고 31건. 기존 버그 행의 `빌드 버전` 미입력은 `BUG_BUILD_VERSION_REQUIRED` 경고로 표시.
